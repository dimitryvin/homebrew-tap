# Homebrew Tap — dimitryvin

Personal Homebrew tap.

## Alpaca Portfolio Monitor

A read-only macOS menu bar app for your [Alpaca](https://alpaca.markets) portfolio.

```bash
brew install --cask dimitryvin/tap/alpaca-portfolio-monitor
```

Or:

```bash
brew tap dimitryvin/tap
brew install --cask alpaca-portfolio-monitor
```

Source: https://github.com/dimitryvin/alpaca-portfolio-monitor
